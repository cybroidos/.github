## CybroidOS

An operating system for engineers, analysts, security teams, schools and
offices: secure from the first boot, kept up to date on its own, and fast on
the computers you already have. Built on Debian and KDE Plasma by
[Cybroid](https://cybroid.com/cybroidos), in Kampala.

- **Two interfaces:** Horizon, calm and familiar; Hex, with system and network
  status always in view.
- **Editions** for security, development, networking, engineering and
  classrooms, from one system.
- **Free software:** GPL-3.0-or-later; the name and artwork are Cybroid's
  trademarks.

**Get it:** [cybroid.com/cybroidos](https://cybroid.com/cybroidos) ·
**Build it:** [cybroidos/os](https://github.com/cybroidos/os) ·

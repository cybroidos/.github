## CybroidOS

**A secure, self-updating desktop operating system for engineers, security teams, schools and offices.**

Built on Debian 13 and KDE Plasma 6 by [Cybroid](https://cybroid.com), Kampala.

[Download](https://cybroid.com/cybroidos) · [Source](https://github.com/cybroidos/os) · [Install guide](https://github.com/cybroidos/os/blob/main/docs/user/INSTALL.md) · [Contributing](https://github.com/cybroidos/os/blob/main/CONTRIBUTING.md)

### Highlights

- **Two interfaces:** *Horizon*, calm and familiar, and *Hex*, with system and network status always in view.
- **Secure and self-maintaining:** a firewall and AppArmor from the first boot, signed automatic updates, no advertising and no tracking.
- **One download, five editions:** Developer, Security, Network, Engineering and Classroom, chosen at first sign-in, with the industry-standard tools of each field.
- **Built for organisations:** fleet management and a private network through [Hangar](https://cybroid.com/hangar).
